Стандартный вид:
./dbms --file file.data --query 'КОМАНДА'
./dbms --file file.data --query 'PRINT mystack' - PRINT mystack

Массив (М/string):
./dbms --file file.data --query 'MPUSH myarray apple' - Добавить элемент в конец массива
./dbms --file file.data --query 'MPUSH myarray banana 0' - Добавить элемент по индексу
./dbms --file file.data --query 'MGET myarray 1' - Получить элемент по индексу
./dbms --file file.data --query 'MSET myarray 0 cherry' - Заменить элемент по индексу
./dbms --file file.data --query 'MDEL myarray 0' - Удалить элемент по индексу
./dbms --file file.data --query 'MLEN myarray'- Получить длину массива

Односвязный список (F/string):
./dbms --file file.data --query 'FPUSH mylist one head' - Добавить в начало (голову)
./dbms --file file.data --query 'FPUSH mylist four tail' - Добавить в конец (хвост)
./dbms --file file.data --query 'FPUSH mylist five after four' - Добавить после элемента
./dbms --file file.data --query 'FPUSH mylist zero before one' - Добавить перед элементом
./dbms --file file.data --query 'FDEL mylist head' - Удалить с головы
./dbms --file file.data --query 'FDEL mylist tail' - Удалить с хвоста
./dbms --file file.data --query 'FDEL mylist before four' - Удалить после элемента
./dbms --file file.data --query 'FDEL mylist after one' - Удалить перед элементом
./dbms --file file.data --query 'FDEL mylist one value' - Удалить по значению
./dbms --file file.data --query 'FGET mylist' - Прочитать весь список (вывести)
./dbms --file file.data --query 'FFIND mylist two' - Поиск элемента (TRUE/FALSE)

Двусвязный список (L/string):
./dbms --file file.data --query 'LPUSH mydlist b head' - Добавить в начало
./dbms --file file.data --query 'LPUSH mydlist e tail' - Добавить в конец
./dbms --file file.data --query 'LPUSH mydlist f after e' - Добавить после элемента
./dbms --file file.data --query 'LPUSH mydlist a before b' - Добавить перед элементом
./dbms --file file.data --query 'LDEL mydlist head' - Удалить с головы
./dbms --file file.data --query 'LDEL mydlist tail' - Удалить с хвоста
./dbms --file file.data --query 'LDEL mylist before e' - Удалить после элемента
./dbms --file file.data --query 'LDEL mylist after b' - Удалить перед элементом
./dbms --file file.data --query 'LDEL mydlist b value' - Удалить по значению
./dbms --file file.data --query 'LGET mydlist' - Прочитать весь список (вывести)
./dbms --file file.data --query 'LFIND mydlist b' - Поиск элемента (TRUE/FALSE)

Стек (S/string):
./dbms --file file.data --query 'SPUSH mystack item2' - Добавить элемент на вершину
./dbms --file file.data --query 'SPOP mystack' - Удалить верхний элемент

Очередь (Q/string):
./dbms --file file.data --query 'QPUSH myqueue last' - Добавить элемент в конец очереди
./dbms --file file.data --query 'QPOP myqueue' - Удалить элемент из начала

Дерево (Complete Binary Tree) (T/int):
./dbms --file file.data --query 'TINSERT mytree 10' - Вставить элемент
./dbms --file file.data --query 'TGET mytree 10' - Поиск элемента в дереве (TRUE/FALSE)
./dbms --file file.data --query 'TCHECK mytree' - Проверка, является ли дерево Complete (TRUE/FALSE)
